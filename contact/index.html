Before you write

  • Emergencies: Call 999 or 112. DispaUK is not an emergency service.
  • Data freshness: Check Status — figures refresh via scheduled sync from MissionChief.
  • API / developers: See Developers for the public JSON endpoints.
  • Privacy: See Privacy and Cookies.

What we can help with

  • Questions about how DispaUK presents MissionChief-derived data
  • Suggestions for the dashboard, map, or locate tools
  • Alliance or operational collaboration (non-emergency)
  • Security or accessibility concerns

What we cannot do

  • Dispatch real-world emergency resources
  • Provide guaranteed live mission feeds (MissionChief does not expose a public missions API for this use)
  • Share account credentials or private session data

Response

Email is monitored when capacity allows. There is no SLA. For urgent safety issues affecting the live website, include URGENT in the subject line.
