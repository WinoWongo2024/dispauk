About DispaUK

Independent UK dispatch information dashboard

What DispaUK is

DispaUK is an independent information site presenting synchronised MissionChief operational summaries — stations, units and personnel totals — for transparency and coordination within the game community.

What DispaUK is not

  • Not a real emergency service
  • Not affiliated with SHPlay GmbH or official MissionChief
  • Not a substitute for 999 / 112

Data source

Operational figures are synchronised periodically from MissionChief UK APIs into a public cache (data/stats.json). Credentials never appear in the browser.

Freshness

The dashboard shows whether data is live, delayed or stale based on the last successful sync time. If MissionChief is unavailable, the last good dataset remains visible with a clear warning.
